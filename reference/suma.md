# Suma numeros

Esta funcion suma dos numeros.

## Usage

``` r
suma(x = 2, y = 4)
```

## Arguments

- x:

  numeros positivos para sumar

- y:

  otro numero positivo para sumar

## Value

vector con la suma de los numeros positivos

## Examples

``` r
suma(3,5)
#> [1] 8
suma(28,78)
#> [1] 106
```
